# 打飞机 · Sky Strike

一个纯 HTML5 Canvas 打飞机小游戏，单文件、零依赖，双击 `index.html` 即可在浏览器中游玩（桌面和手机均可）。

## 玩法

- 击落敌机得分，敌机会越来越快、越来越多
- 每约 6000 分出现一个 Boss，Boss 血量过半后进入狂暴弹幕模式
- 吃道具强化自己：
  - **P**（蓝色）：火力升级（最高 3 级，中弹会降 1 级）
  - **B**（黄色）：+1 炸弹（清屏并清除所有敌方子弹）
  - **❤**（绿色）：+1 生命
- 最高分自动保存在本地（localStorage）

## 操作

| 平台 | 操作 |
| --- | --- |
| 键盘 | 方向键 / WASD 移动，自动开火，`B` 放炸弹，`P` 暂停，空格开始/重开 |
| 触屏 | 单指拖动控制（飞机在手指上方），双指点击放炸弹，点击屏幕开始/重开 |

## 技术说明

- 480×720 逻辑分辨率，自适应缩放并支持高 DPI 屏幕
- 音效由 WebAudio 实时合成，无任何外部资源
- 敌机分小型 / 中型（瞄准射击）/ 大型（三连发）/ Boss（扇形与环形弹幕）四类
- 难度随时间线性提升（刷新频率、血量、弹速）
